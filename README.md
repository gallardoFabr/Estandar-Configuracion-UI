# Estandar-Configuracion-UI
Es un programa que te ayuda a poder realizar el estandar de interfaz de usuario. Permitiendote mostrarle al usuario de manera interactiva el diseño de la propia interfaz, basada solamente en un proyecto de un colegio con un layout fijo. Permite visualizar el diseño de botones, iconos, colores, mensajes de error, modal, etc.
